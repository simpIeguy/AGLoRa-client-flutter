# Поиск БЛА

Приложение для Android, которое показывает, где находятся трекеры: подключённый к телефону по Bluetooth и все, чьи координаты он получил по радио (LoRa). Главная задача — быстро найти упавший БЛА, но приложение подходит для любого объекта с трекером.

## Что умеет

- Роли по имени трекера в прошивке: `UAV1`…`UAV9` — «БЛА 1»…, `GROUND1`…`GROUND9` — «Человек 1»…. Остальные имена показываются как есть, в конце списка.
- Порядок списка: сначала БЛА на связи, затем БЛА с потерянной связью, БЛА в ожидании, люди и остальные. Трекеры без данных 7 дней уходят в свёрнутый архив.
- Цвет карточки и надпись рядом: синий — подключён к телефону, зелёный — «Связь есть» (точка моложе 1 минуты), жёлтый — «Связь пропадает» (1–5 минут), серый — «Связь потеряна» (больше 5 минут).
- Стрелка и расстояние от телефона до трекера. Если нет GPS телефона или компас неточный, стрелка серая, а рядом написана причина. Двойной тап или долгое нажатие на стрелку открывает полный экран на чёрном фоне.
- Координаты на карточке: кнопка копирования и долгое нажатие. Лог последних 50 точек, кнопка «Открыть в картах».
- «Ждать трекер»: имя распознаётся при вводе (`uav-1` → «БЛА 1»). Когда трекер впервые выходит на связь, приложение подаёт сигнал со звуком и вибрацией. Так же оно сообщает о любом новом БЛА, это можно выключить.
- «Кого показывать»: людей можно скрыть, БЛА и свой трекер видны всегда.
- Индикаторы GPS телефона («GPS ±6 м») и компаса («Компас точный»).
- Карта: схема, спутник и гибрид, поворот по компасу телефона.
- Демо-режим без трекеров и Bluetooth (только в отладочной сборке).

Пока не умеет (нужны решения владельца): запоминать трекеры после перезапуска, присылать системные уведомления и работать при выключенном экране.

## Сборка (Windows)

Нужны Flutter SDK и Android SDK (через Android Studio).

```bash
flutter pub get
```

```bash
flutter build apk --debug
```

Готовый файл: `build/app/outputs/flutter-apk/app-debug.apk`. У приложения свой идентификатор `by.tsp.tracker`, поэтому старая сборка (`com.example.aglora_client`) ставится рядом как отдельное приложение, её нужно удалить вручную.

Если сборка падает с ошибкой `Unable to establish loopback connection`, перед сборкой выполните в PowerShell (папка `C:\Temp` должна существовать):

```bash
$env:JAVA_TOOL_OPTIONS='-Djdk.net.unixdomain.tmpdir=C:\Temp'
```

Bluetooth в эмуляторе Android не работает: связь с трекером проверяется на настоящем телефоне.

## Демо-режим

Работает только в отладочной сборке. На стартовом экране кнопка «Демо-режим»: выбрать сценарий и скорость (×1 или ×10).

Сценарий можно запустить сразу, без нажатий:

```bash
flutter run --dart-define=DEMO_SCENARIO=search --dart-define=DEMO_SPEED=10
```

Сценарии (`assets/demo/`):

| Сценарий | Что проверяет |
|---|---|
| `normal` | подключённый трекер и второй трекер шлют точки и двигаются |
| `no_own_points` | приходят только точки второго трекера (так было до исправления прошивки) |
| `link_loss` | второй трекер замолкает: цвет меняется на жёлтый, потом серый |
| `ragged` | сообщения кусками, склеенные и битые |
| `many` | пять трекеров одновременно |
| `search` | поиск БЛА: телефон на трекере GROUND1, UAV1 выходит на связь через 40 с, UAV2 пропадает, ещё один человек и трекер со старым именем |

Сценарии делает скрипт из записанного трека NMEA:

```bash
dart run tool/make_demo_scenarios.dart ../emulator/src/main/resources/data/round1.txt assets/demo
```

## Проверки

Формат, анализатор и тесты одной командой:

```bash
powershell -File tool/check.ps1
```

## Устройство кода

`lib/protocol` — протокол трекера, `lib/data` — трекеры и их состояние, `lib/services` — Bluetooth, GPS, компас, `lib/ui` — экраны, тема и все тексты (`strings.dart`). Отчёт об устройстве и найденных проблемах: `docs/audit.md`.

## Протокол

Трекер присылает по Bluetooth текстовые сообщения вида `AGLoRa-<тип>&ver=…&ключ=значение…|`. Приложение понимает типы `point` (точка трекера) и `memory` (состояние памяти и имя подключённого трекера) и отправляет трекеру запросы `all`, `crc`, `clear`, `id<N>`. Формат задаёт прошивка трекера, менять его в приложении нельзя без правки прошивки.
